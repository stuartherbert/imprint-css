## Introduction

### What's In This Section?

Imprint CSS includes over 2,000 named colors that you can use in Tailwind CSS v3 or import directly into your Javascript and Typescript projects.

To stop that spiralling into madness [too late! - ed.], we've organised them into separate Color Collections. There's a dedicated page for each color collection (such as <InternalLink slug="colors/imprint-css-collection"/>), where you can see exactly what each color looks like as a series of artists' swatches.

Every individual color (such as <ColorLink colorName="imprint-blackgold"/>) gets a dedicated page too. You can access those by clicking on the color swatches on our color collection pages.

### Why Does Imprint CSS Ship With So Many Colors?

In a world where so many physical products are only manufactured in the same drab and dull tones, color is more important than ever.

Color is one of the key tools we all use to personalise things. Whether it's company branding or just personal preference, choosing our own colors helps us feel like we've made something ours.

But it isn't just the ability to customise component colors that matters. Using colors from familiar palettes can help our work fit in to the ecosystem where it is going to be used. It helps our work look like it belongs.

These include several popular "ecosystem" color palettes, including colors familiar to

* <InternalLinkWithText slug="colors/apple-collection" text="Apple OSX / MacOS users"/>,
* <InternalLinkWithText slug="colors/material-design-collection" text="Android / Google users"/>,
* <InternalLinkWithText slug="colors/microsoft-design-language-collection" text="Microsoft users"/>,
* <InternalLinkWithText slug="colors/bootstrap-collection" text="Bootstrap users"/>,

and more.

We also include a wide collection of <InternalLinkWithText slug="colors/wikipedia-collection" text="colors originally documented on Wikipedia"/>. If you're looking for seed colors for your next color theme, maybe you'll find inspiration there!

There is another reason why we're collecting as many colors as we can.

### Detailed Color Accessibility Analysis Of Every Single Color

We want to document all these colors, so that we can quickly and easily understand which colors are accessible ... and which are not.

Color accessibility standards have been around for decades, but awareness and adoption is far from complete. That has to change. Did you know that color accessibility standards are becoming a legal requirement (depending on your target audience)?

(<InternalLinkWithText slug="colors/color-contrast" text="You can do a (very) deep dive into it here"/>.)

To help you make great color choices, every color's dedicated page includes:

* a list of which accessibility standards it complies with (if any!),
* clear guidance on what a color can be accessibly used for; and
* visual examples of the color in use (so you can see if it's a tasteful color or not!)

If there's any further information you think we could add to each color's dedicated page, let us know!

### Our Definition Guarantee

We're committed to keeping our color definitions the same once they have been published. We'll only change the color definitions:

1. to fix clear errors in the definition (ie fix typos in the color definition), or
2. if an "official" definition becomes available from the color's originator (e.g. ANSI publishes official RGB or CSS color definitions for the Safety colors).

You can use these colors knowing that they're going to still exist long into the future.

### Intellectual Property Disclaimer

We believe that every color that ships in Imprint CSS is either available under an open / permissive license, or can be reasonably claimed under fair use. You'll find details about where we sourced the colors from on each of the color collection pages.

## Discussion

### Grey or Gray?

Imprint CSS uses the spelling 'gray' everywhere (except for when we've lapsed back into British English by mistake!).

In English, there are two different spellings for the color grey:

* _grey_ is the British English spelling, and is the predominant spelling outside of America
* _gray_ is the American English spelling

(Isn't English fun?)

In computing, _gray_ is the accepted spelling. ([Wikipedia says that this stems from the X11 color names list](https://en.wikipedia.org/wiki/X11_color_names)). That's why Imprint CSS uses _gray_ and not _grey_.
