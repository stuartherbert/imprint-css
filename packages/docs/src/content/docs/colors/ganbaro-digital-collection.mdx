## Introduction

### What Is The Ganbaro Digital Color Collection?

<ExternalLink name="Ganbaro Digital Homepage" text="Ganbaro Digital Ltd"/> is a UK-based software development consultancy founded by Stuart Herbert in 2015. It is the main sponsor of Stuart's work on Imprint CSS.

This collection consists of the in-house color palettes that Ganbaro uses in its own creations.

### Where Did The Color Names Come From?

The color names are all taken from Ganbaro Digital's in-house design guidelines.

We've just added the `ganbaro-` prefix to keep them separate from all of the other color collections.

### Intellectual Property Disclaimer

These colors were taken from (as yet) unpublished internal Ganbaro Digital documentation.

The Imprint CSS project claims no ownership of these colors.
