## Introduction

### What Is The Metro UI Color Collection?

<ExternalLink name="Metro_UI Homepage" text="Metro UI"/> is an open-source frontend framework from Ukraine. It's a mobile-first alternative to Bootstrap, originally launched in 2012.

We first came across it via <ExternalLink name="MaterialUI Metro Colors" text="MaterialUI's list of Metro colors"/>, while looking for Microsoft's Metro colors.

We've made them available in Imprint CSS so that you can build websites and web-based apps that fit in with existing Metro UI sites and apps.

### Where Did The Color Names Come From?

We've taken the color names from the <ExternalLink name="Metro_UI Colors" text="Metro UI documentation"/>.

We've just added the `metro-` prefix to keep them seperate from all other color collections.
