These colors are used in the Imprint CSS utility and component classes.

## The Colors

### Page and Text Colors

These colors are the default foreground and background colors.

We've chosen these colors because they're more readable than pure black on white. This color pair meets the WCAG 2.2 AAA standard for headings, bold text and body text.

## Semantic Colors

### Main Semantic Colors

Imprint CSS uses these colors for the `--imprint-*` semantic styles.

`imprint-red`, `imprint-green`, `imprint-blue` and `imprint-yellow` are used for notices, warnings and errors. They are based on international standards for physical notices.

The `imprint-primary` and `imprint-secondary` colors mostly exist to help us test the `--imprint-primary` and `--imprint-secondary` semantic classes.

All of these colors meet the WCAG 2.2 AAA standard for headings and bold text. Use them as background colors.

Try not to use them for body text. They don't all meet the WCAG 2.2 AAA standard for body text.

### Semantic Accent Colors

The `imprint-accent*` colors are used for border elements against the main Imprint CSS semantic colors. They've been hand-chosen to complement the main semantic colors.

Do not use these colors for any text elements, as they are not guaranteed to meet the WCAG 2.2 AAA standard. Only use them for UI / decorational elements.
