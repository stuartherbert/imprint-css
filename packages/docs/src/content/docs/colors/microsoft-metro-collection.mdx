## Introduction

### What Is The Microsoft Design Language v1 Color Collection?

The Microsoft Design Language v1 is best known as "Metro".

"Metro" was the internal codename that Microsoft used for one of its earliest attempts at a design language. It belonged to the <ExternalLink name="Wikipedia Flat Design" text="flat design"/> school of design. It was the main design language for the Windows Phone platform, before being adopted by Xbox, Windows 8 and other Microsoft products.

It was replaced by Microsoft Design Language (MSDL) v2 as Microsoft transitioned to Windows 10. As far as we know, "Metro" was never formally called MSDL v1, but we think it's a fitting name for the collection.

### Where Did The Color Names Come From?

As far as we know, Microsoft never published public names for any of the Metro colors.

We've taken the names (and definitions) from <ExternalLink name="Colorlib Metro Colors" text="Colorlib's list of Metro colors"/>. The list of names on Colorlib match up with other sites that publish a list of Metro colors.

### Intellectual Property Disclaimer

We've been unable to find any official Microsoft website about the "Metro" / MSDL v1 colors. While they may be abandoned or in the public domain, they may be the intellectual property of Microsoft. There may be legal restrictions on when and how you can use these colors.
