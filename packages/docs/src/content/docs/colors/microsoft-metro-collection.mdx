## Introduction

### What Is The Microsoft Metro Color Collection?

"Metro" was the internal codename that Microsoft used for one of its earliest attempts at a design language. It belongs to the <ExternalLink name="Wikipedia Flat Design" text="flat design"/> school of design. It was the main design language for the Windows Phone platform, before being adopted by Xbox, Windows 8 and other Microsoft products.

It was replaced by the Microsoft Design Language as Microsoft transitioned to Windows 10.

Although long gone, we think that Metro was iconic for its time, and its colors worth preserving - both for historical purposes, and because the colors have stood the test of time.

### Where Did The Color Names Come From?

As far as we know, Microsoft never published public names for any of the Metro colors.

We've taken the names from <ExternalLink name="MaterialUI Metro Colors" text="MaterialUI's list of Metro colors"/>.
