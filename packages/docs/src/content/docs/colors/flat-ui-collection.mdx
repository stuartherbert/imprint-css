## Introduction

### What Is The Flat UI Color Collection?

<ExternalLink name="Wikipedia Flat Design" text="Flat design"/> is a minimalist design language or design style that was popular with graphical user interfaces from around 2006-2018. Later design languages have built on the flat design principles of simplicity and minimalism while adding visual depth, motion and lighting to improve usability.

<ExternalLink name="Flat UI Homepage" text="Flat UI by designmodo"/> is perhaps the flatest of all flat design frontend frameworks. It uses colors that are quite similar to the original 16-color VGA graphics of old. It provides complementary light and dark shades of each color.

We've made those colors available in Imprint CSS because they create a look that encapsulates an era.

### Where Did The Color Names Come From?

Flat UI names all of its colors.

We've just added the `flat-` prefix to the front of the color names, to keep them separate from colors from any other color collection.
