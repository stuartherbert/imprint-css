### What Is The Wikipedia Colors Collection?

The Wikipedia Colors Collection are named colors that we've found on Wikipedia.

### Where Did The Color Names Come From?

Every color must have a prefix of some kind, to avoid clashing with present (and future!) <InternalLinkWithText slug="colors/css-extended-colors-collection" text="named colors from the CSS standards"/>.

* many of the colors (e.g. `crayola-`, `isccnbs-`) are grouped by where Wikipedia sourced them from;
* some colors are grouped by association with a culture (e.g. `french-`, `spanish-`) or by association with an organisation (e.g. `usaf-`); and
* we use the `misc-` prefix for colors that don't fall into any other category.

We follow the CSS & SVG standards' conventions when normalising names:

* lower-case ASCII characters only; and
* all words concatenated together.

The results aren't the most accessible (to put it mildly), and it doesn't do a great job of respecting non-English speaking communities either.

### Some Of These Colors Are Duplicates!

We look at each duplicate on a case-by-case basis. In general, we're following this train of thinking:

* Some colors are known by multiple names. Those are allowed (as long as the multiple names aren't in the `misc-` group).
* If we had two (or more) names that just had different prefixes (e.g. `example1-fakecolor`, `example2-fakecolor`), we'd add them all. We'd rather have complete color groups where possible.
* We try to keep duplicate colors with the same name out of the `misc-` group (e.g. if `misc-fakecolor` and `example1-fakecolor` shared the same definition, we wouldn't publish `misc-fakecolor`).

If we do publish a duplicate color that breaks these rules, we'll keep it. We try to avoid removing colors once they are published in a tagged release, to minimise disruption to you.

### Color Accuracy

Many of these colors are approximate. Their original definitions are either pre-digital, or are in color spaces that can't always translate perfectly to RGB colors.

It's not unusual for Wikipedia to revise the color definitions over time, either.

### X11 Colors

The <ExternalLink name="Wikipedia X Window System" text="X Window System"/> (commonly referred to as "X11") defined many of the named colors that are now part of the <InternalLinkWithText slug="colors/css-extended-colors-collection" text="CSS Extended Colors"/>.

However, some <ExternalLink name="Wikipedia X11 named colors" text="X11 named colors"/> never made it into the CSS named colors list:

* some X11 color names clash with CSS named colors;
* some X11 color names aren't official names (e.g. they're part of the PWG 5101.1 derived color list)

We've added them to Imprint CSS with the `x11-` prefix.

<ColorCollection colorGroup="wikipedia" prefix="x11"/>

Wikipedia sourced these colors from the <ExternalLink name="Wikipedia Xona Games" text="Xona Games"/> color list.

## Discussion

### Why No Pantone Colors?

We'd love to make Pantone's colors available in Imprint CSS. For many design professionals, they're the biggest name in color.

Unfortunately, <ExternalLink name="Wikipedia Pantone" text="according to Wikipedia"/>, Pantone asserts that their lists of color numbers and pigment values are the intellectual property of Pantone and free use of the list is not allowed.
