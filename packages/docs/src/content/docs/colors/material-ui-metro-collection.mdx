## Introduction

### What Is The Material UI Metro Color Collection?

<ExternalLink name="MaterialUI Homepage" text="The Material UI website"/> was one of the first places that collected color palettes and shared them as click-to-copy colors. One of those color collections is <ExternalLink name="MaterialUI Metro Colors" text="a list of Metro colors"/>.

"Metro" is a name has been used by different frameworks over the years. Which "Metro" does the Material UI website document?

* <ExternalLink name="MaterialUI 2016 Homepage" text="Back in 2016, the Material UI site said that these were the Microsoft Metro colors"/>. That claim disappeared <ExternalLink name="MaterialUI Jun 24 2021 Homepage" text="by Jun 24th 2021"/> when the site's look and feel was refreshed.
* These colors share a lot of names with the <ExternalLink name="Metro_UI Colors" text="Metro UI color palette"/>, and (at the time of writing in early 2025) "Metro UI" is mentioned in the page's HTML metadata.

Thing is, the Material UI Metro colors are different to the equivalent colors from Metro UI. Both collections also contain colors not found in the other. If they shared a common ancestor or inspiration, they've definitely diverged since.

We think it's best to treat the Material UI Metro colors as a distinct color collection, and just enjoy them in their own right for what they offer.

### Where Did The Color Names Come From?

We've taken the color names from <ExternalLink name="MaterialUI Metro Colors" text="Material UI's Metro colors page"/>.

We've just added the `matmet-` prefix to keep them seperate from all other color collections.

### Intellectual Property Disclaimer

The colors were originally published in 2016 without any copyright notice (presumably as they were originally claimed to be the Microsoft Metro colors?)
