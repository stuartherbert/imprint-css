## Introduction

### What Is The Microsoft Design Language (MSDL) v2 Color Collection?

The Microsoft Design Language v2 (aka MSDL v2) was the official successor to Microsoft's "Metro" design language. The name "Microsoft Design Language" was introduced in September 2012. It was succeeded by the Fluent Design System in 2017. (<ExternalLink name="Wikipedia Metro Design Language" text="source"/>)

MSDL v2 introduced a rich "universal color palette" (Microsoft's term) of shades and tones of various colors. These could take advantage of improvements in screen quality at the time. They allowed for more nuance and a more sophisticated look than "Metro" provided.

### Where Did These Colors Come From?

We took these colors from https://www.microsoft.com/en-us/design/color in April 2017. Unfortunately, this page is long gone. It was indexed by the Wayback Machine in 2018, but alas the archive hasn't preserved the page's original formatting.

Microsoft never published official names for any of these colors. We've come up with our own names, using the closest match (in our opinion) to either the <InternalLinkWithText slug="colors/css-extended-colors-collection" text="CSS Extended Colors Collection"/> or <InternalLinkWithText slug="colors/wikipedia-collection" text="Wikipedia Colors Collection"/>.

We've no record of whether Microsoft organised the colors into separate palettes (such as `msdl2-falured-1` to `msdl2-falured-7`), or if we did.
