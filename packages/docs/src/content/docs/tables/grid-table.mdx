## Introduction

Imprint CSS supports a "grid" look to tables.

### How To Use

There are two ways to make your tables have the "grid" styling:

1. Add `table-grid` to your `<table>` HTML tag, or
2. Add `table-grid` to your `<body>` tag (or any other suitable parent tag) to make all your tables have this style

## Example Tables

### Basic Table

This is a basic table with minimal content.

<table class="table-grid">
    <thead>
        <tr>
            <th>Column 1</th>
            <th>Column 2</th>
            <th>Column 3</th>
        </tr>
    </thead>
